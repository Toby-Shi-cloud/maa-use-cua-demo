# 明日方舟 gesture+scroll 实测（2026-09-28）

注意：本文是起点 began 修复前的历史实验。后续生成器改为先在 from 发零位移 began，
下面的校准命令尚未在新生成器上复验，不应当作新版已验证参数。

目标：从 screenshots/arknights_1.png 的暂停状态，拖动下方第二个干员桃金娘，
进入 screenshots/arknights_2.png 对应右上格子的朝向选择。没有确认朝向或恢复战斗。

## 历史候选命令

应用名为 `Arknights`（大小写敏感）。窗口原生截图为 3942×2280，窗口尺寸
1971×1140 points，backing scale=2。保持此尺寸，输入命令不要加 `--max-dimension`。

```sh
./build/cua-shot --app Arknights --gesture \
  --from-x 400 --from-y 2200 --to-x 3650 --to-y 190 \
  --steps 20 --duration-ms 400
```

3 次中 2 次进入参考图二的同一个目标格（build/ark-study/t05.png、t07.png）；
第 2 次 t06.png 回到图一，未记录中间帧，失败原因未隔离。
每次复验前取消，并截图确认恢复图一。400 ms 是手势序列时间，不包括 CLI 初始化、截图。
这是可命中的候选参数，尚不稳定；不是连续坐标精度证明。

已经落格、等待选择朝向时，点击窗口中心取消：

```sh
./build/cua-shot --app Arknights --gesture-click --x 1971 --y 1140
```

仅选中卡片、尚未落格时，再点一次卡片取消：

```sh
./build/cua-shot --app Arknights --gesture-click --x 539 --y 2117
```

## 过程与限制

- 最初使用 2048×1185 缩图坐标的两次拖动与一次 tap 无效。检查发现 gesture / gesture-click
  将坐标直接除以 metadata.screenshot_scale=2，但缩图后的实际 pixels/point 为 2048/1971。
  所以缩图坐标没有投递到预期位置。这些结果不用于评价步数或时长。本轮记录问题，未改代码。
- 改为原生坐标后，10 步 / 400 ms，从 (308,2271) 到 (2887,577)，结束仍为图一。
  未捕获过程中间帧，不能区分没拖起和无效落点后自动重置。
- 原生坐标 tap (539,2117) 可选中桃金娘。仅选中时点击中心未取消；按用户说明再次点卡片成功取消。
- 改为上方 20 步 / 400 ms 命令，3 次中 2 次成功。与 10 步实验的起终点不同，
  不能将成功归因于步数本身，也不能套用 Sample 的补偿倍率。
- 生成器首个事件在 i=1，所以上方命令首个位置为 (562.5,2099.5)，落在桃金娘卡片中。
  `from` 不是实际第一个事件位置，`to` 也不能直接当作游戏最终触点。
- 使用后台投递路径，但中途为诊断取消状态调用过普通 --click，之后窗口标题栏呈激活状态。
  本轮未独立验证成功时游戏处于后台，不能作为“失焦仍成功”的证据。
- 当轮实验结束时曾保留图二的目标格朝向选择状态，便于用户检查；
  这不是当前游戏状态。

当轮截图保留在本地忽略目录 build/ark-study/，当时未修改生成器或恢复 Option stash。

## 2026-09-30 输入端逐步配对初试

在 Sample 的逐步暂停法取得连续 10 次相同落点后，使用未修改的 Arknights
接收端测试 `CUA_GESTURE_GATE=step`，20 步、400ms。

- 从 `(400,2200)` 到 `(3650,190)`：成功触发桃金娘拖动和朝向选择，
  但落在参考格左下方的另一格。普通前台点击红色 X 后，截图确认恢复实验起点。
- 从 `(400,2200)` 到 `(3930,10)`：拖动预览到目标格附近，但没有进入朝向选择；
  终点位于窗口顶端，是否因释放位置导致失败尚未隔离。随后点击干员卡片，
  预览消失，但最后截图仍显示绿色可放置格和干员面板，未确认恢复起点。

用户随后明确：格子坐标差由 MAA 算法处理，当前实验可以暂停，后续以 MAA 实际
指令调试。因此没有继续移动目标、点击格子或运行更多游戏试次。**游戏中尚未证明
同一指令可重复落在同一格**；Sample 的 10/10 不能替代这项验证。下一轮应先确认
游戏已回到初始状态，固定 MAA 给出的起终点与窗口尺寸，对同一指令多次执行，
逐次记录截图中的格子和选中/朝向状态。

本地截图与发送时间记录：`build/ark-study/step-gate-*.png`、
`build/ark-study/step-gate-*.csv`。逐步暂停目前仅由诊断环境变量启用。
